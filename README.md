One sentence that explains the modern internet to a time traveler who has just stepped out of the year 1800 — written using only words and images an 1800 person would know: no word coined after their time, just a picture they could hold in their head.

> "It is a library with no walls, where every book in the world sits upon one table and any man may read any page and speak to its author at once."

## Run it

```sh
npx tsx main.ts   # writes the sentence to /output/entry.txt
```

The program is deterministic: it always writes the same single sentence (143 characters, one line, valid UTF-8).
